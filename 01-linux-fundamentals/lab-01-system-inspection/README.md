
# Linux System Inspection Lab

## Objective
Inspect and understand Linux system resources
using native command-line utilities.

## Skills Demonstrated
- Linux kernel identification
- CPU architecture inspection
- Memory usage analysis
- Process monitoring
- Filesystem utilization
- Bash scripting

## Run
```bash
chmod +x system-report.sh
./system-report.sh
```

## Environment
Windows + WSL2 Ubuntu

## Kubernetes Relevance
Kubernetes worker nodes rely on Linux to
manage processes, memory, CPU and storage.
Understanding these resources is essential
for diagnosing node and workload failures.
